# Raynath Theme

A modern, responsive WordPress theme designed specifically for raynath.com, featuring clean design and local community focus for Atlantic, Iowa and surrounding areas.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI**: Clean, modern design with gradient headers and card-based layouts
- **Local Community Focus**: Designed with local community content in mind
- **Customizable**: Theme customizer options for colors and branding
- **SEO Friendly**: Semantic HTML5 markup and optimized structure
- **Accessibility**: WCAG compliant with proper ARIA labels and keyboard navigation
- **Performance**: Optimized CSS and JavaScript for fast loading
- **Widget Ready**: Multiple widget areas for sidebar and footer content

## Installation

1. Upload the `raynath-theme` folder to your WordPress `/wp-content/themes/` directory
2. Activate the theme through the 'Appearance' menu in WordPress
3. Customize the theme through the WordPress Customizer

## Theme Customization

The theme includes several customization options available in the WordPress Customizer:

- **Header Background Color**: Customize the header background color
- **Accent Color**: Set the theme's accent color for buttons and links
- **Footer Description**: Customize the footer description text
- **Site Logo**: Upload a custom logo
- **Menus**: Create and manage navigation menus

## Template Files

- `index.php` - Main template file
- `header.php` - Site header
- `footer.php` - Site footer
- `sidebar.php` - Sidebar template
- `single.php` - Single post template
- `page.php` - Static page template
- `search.php` - Search results template
- `404.php` - 404 error page template

## Widget Areas

- **Sidebar**: Main sidebar widget area
- **Footer Widget 1**: First footer column
- **Footer Widget 2**: Second footer column
- **Footer Widget 3**: Third footer column
