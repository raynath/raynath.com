# 420.school

This repository includes a minimal WordPress theme for 420.school.

## WordPress Theme

- Theme path: `wp-content/themes/420school/`
- Activate in WordPress: Appearance → Themes → 420.school
- Set a static homepage: Settings → Reading → Your homepage displays → A static page

### Assets

- Move `PXL_20231209_050307132.jpg` into `wp-content/themes/420school/assets/` so the homepage image renders.

### Development

- Edit `front-page.php` for the homepage hero and content.
- Global styles live in `style.css`.
